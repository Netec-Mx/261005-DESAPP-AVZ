# Desarrollo de aplicaciones para ambientes Web Avanzado

Este curso introduce al participante al desarrollo full-stack utilizando Laravel (PHP, Python) como backend y un frontend basado en Blade, componentes reutilizables y consumo de APIs. Se cubren fundamentos del framework, manejo de MySQL, autenticación, seguridad esencial, desarrollo de APIs y su integración con interfaces web. También se introduce el uso de servicios de Inteligencia Artificial desde Laravel (PHP, Python). El curso culmina con un proyecto final full-stack integrador.

## Lista de laboratorios

### Capítulo 1

- [7 Práctica: Fundamentos de Laravel 13.x y desarrollo full-stack con PHP 8.5.x, Composer 2.10.3+, Node.js 24.21.0 LTS, npm 11.x, Vite y Tailwind CSS 4.x](Capitulo01/README.md#7-práctica-fundamentos-de-laravel-13x-y-desarrollo-full-stack-con-php-85x-composer-2103-nodejs-24210-lts-npm-11x-vite-y-tailwind-css-4x)
  - Descripción: Desarrollar una aplicación full-stack de fundamentos con PHP 8.5.x y Laravel 13.x, preparando el entorno con Composer 2.10.3 o superior, Laravel Installer y Git 2.55.0 o superior. La práctica integra rutas Web y API, controladores, vistas y componentes Blade reutilizables, además de una interfaz simple con Tailwind CSS 4.x. Para los recursos frontend se utiliza Node.js 24.21.0 LTS, npm 11.x y Vite en la versión incluida en Laravel 13. El trabajo se realiza en Visual Studio Code y se valida en Google Chrome, Microsoft Edge o Firefox actualizados.
  - Duración estimada: 180 min
  - [Ver capítulo completo](Capitulo01/README.md)

### Capítulo 2

- [8 Práctica: Desarrollo CRUD con Laravel 13.x, PHP 8.5.x y MySQL 8.4.x](Capitulo02/README.md#8-práctica-desarrollo-crud-con-laravel-13x-php-85x-y-mysql-84x)
  - Descripción: Construir un CRUD full-stack con PHP 8.5.x, Laravel 13.x y MySQL 8.4.x. La práctica contempla la configuración de la conexión, migraciones, modelos Eloquent, operaciones CRUD, relaciones simples, formularios Blade, validaciones, paginación y ordenamiento desde el backend, manteniendo el proyecto y sus dependencias con Composer 2.10.3 o superior y Git 2.55.0 o superior.
  - Duración estimada: 180 min
  - [Ver capítulo completo](Capitulo02/README.md)

### Capítulo 3

- [7 Práctica: Autenticación y gestión básica de roles con Laravel 13.x y MySQL 8.4.x](Capitulo03/README.md#7-práctica-autenticación-y-gestión-básica-de-roles-con-laravel-13x-y-mysql-84x)
  - Descripción: Implementar en Laravel 13.x un flujo de autenticación web con registro, login y logout, utilizando middleware para proteger rutas y módulos. La práctica incluye la gestión de roles simples almacenados en MySQL 8.4.x y la personalización de las vistas de autenticación, manteniendo el enfoque del capítulo en autenticación básica y control de acceso dentro de la aplicación.
  - Duración estimada: 180 min
  - [Ver capítulo completo](Capitulo03/README.md)

### Capítulo 4

- [7 Práctica: Seguridad esencial en aplicaciones con PHP 8.5.x y Laravel 13.x](Capitulo04/README.md#7-práctica-seguridad-esencial-en-aplicaciones-con-php-85x-y-laravel-13x)
  - Descripción: Aplicar controles esenciales de seguridad en una aplicación desarrollada con PHP 8.5.x y Laravel 13.x: validación segura, protección CSRF, prevención básica de XSS, buenas prácticas en formularios, hashing de contraseñas y manejo seguro de archivos subidos. La práctica verifica que los controles se mantengan integrados con la configuración y convenciones del proyecto Laravel 13.x.
  - Duración estimada: 180 min
  - [Ver capítulo completo](Capitulo04/README.md)

### Capítulo 5

- [8 Práctica: Desarrollo y consumo de APIs con Laravel 13.x, Laravel Sanctum y Bruno o Postman](Capitulo05/README.md#8-práctica-desarrollo-y-consumo-de-apis-con-laravel-13x-laravel-sanctum-y-bruno-o-postman)
  - Descripción: Desarrollar una API REST en Laravel 13.x mediante rutas API, controladores y respuestas JSON, incorporando manejo de errores y formularios que interactúan con la API desde el frontend mediante JavaScript o fetch(). La práctica incluye la protección de endpoints con Laravel Sanctum y la validación de solicitudes y respuestas mediante Bruno o Postman, alineando el ejercicio con el consumo de APIs desde el frontend.
  - Duración estimada: 210 min
  - [Ver capítulo completo](Capitulo05/README.md)

### Capítulo 6

- [5 Práctica: Integración full-stack con Laravel 13.x, Blade, Vite, Inertia.js, Vue 3.x o React 19.x, TypeScript y Tailwind CSS 4.x](Capitulo06/README.md#5-práctica-integración-full-stack-con-laravel-13x-blade-vite-inertiajs-vue-3x-o-react-19x-typescript-y-tailwind-css-4x)
  - Descripción: Integrar una solución full-stack con PHP 8.5.x y Laravel 13.x utilizando Blade, JavaScript y Vite en la versión incluida en Laravel 13. Para el frontend se emplean Node.js 24.21.0 LTS, npm 11.x y Tailwind CSS 4.x, incorporando Inertia.js con Vue 3.x o React 19.x y TypeScript en la versión definida por el proyecto frontend. La práctica incluye pruebas mínimas con PHPUnit 12.x o Pest 4.x.
  - Duración estimada: 150 min
  - [Ver capítulo completo](Capitulo06/README.md)
